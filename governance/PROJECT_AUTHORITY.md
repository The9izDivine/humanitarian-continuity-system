Project Authority
1. Repository Authority

Ashley Harris, operating through The9izDivine, is the originating project authority for Version 0.1.0.

2. Protected Decisions

The following require explicit owner approval:

repository transfer;
repository deletion;
visibility changes;
license adoption or revision;
ownership statements;
external affiliation claims;
use of ORYNTH material;
commercial assignment;
release publication;
production deployment;
use of real personal data;
integration with external systems;
addition of official partners;
installation of privileged GitHub applications.
3. Contributor Authority

Contributors may propose changes through reviewable commits or pull requests.

Contribution does not grant authority to:

bind the project;
represent external affiliations;
change ownership;
relicense material;
publish releases;
commit real sensitive data;
claim operational readiness.
4. Decision Record

Every protected decision must record:

decision identifier;
date;
decision maker;
scope;
evidence;
affected files;
outcome;
conditions;
superseded decisions.
