Release Authority
1. Release Classification

A release must be classified as one of:

INTERNAL_DEVELOPMENT
PUBLIC_REFERENCE
DEMONSTRATION
PILOT_CANDIDATE
PRODUCTION_CANDIDATE
WITHDRAWN

Version 0.1.0 is limited to:

PUBLIC_REFERENCE
DEMONSTRATION
2. Release Preconditions

No release may be published until:

ownership statements are verified;
external-affiliation language is reviewed;
only synthetic data is present;
tests pass;
schemas validate;
no secrets are detected;
no real beneficiary or volunteer information is present;
no ORYNTH Reserved Property is included;
limitations are documented;
version and release notes are complete.
3. Production Restriction

No release may be described as production-ready without a separate security, privacy, legal, operational, accessibility, and domain-expert review.

4. Withdrawal

A release must be withdrawn or corrected if it contains:

unsupported affiliation claims;
exposed sensitive information;
unauthorized intellectual property;
dangerous operational guidance;
materially invalid decision logic;
misleading readiness claims.
